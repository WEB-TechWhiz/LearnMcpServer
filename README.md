## 📌 Overview
**LearnMcpServer** is designed to provide a comprehensive, maintainable, and scalable solution in the **AI Tools / Model Context Protocol** domain. Engineered with modern industry standards and clean architecture.

---

## ✨ Key Features
- **Custom Tool Handlers**: Expose executable backend tools to AI assistants
- **Resource Providers**: Stream live data and document context via MCP standard
- **Full JSON-RPC Protocol**: Fully compliant with Anthropic and OpenAI MCP standards

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.x or higher recommended)
- **npm**, **yarn**, or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/WEB-TechWhiz/LearnMcpServer.git
   cd LearnMcpServer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```


5. **Start the development server:**
   ```bash
   node index.js
   ```
